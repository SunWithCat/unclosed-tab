# 未关闭的标签

一部住在浏览器里的短篇 galgame。

女主叫**栞**（书签的栞）。这个标签页是她的房间。你存档、读档、回滚、刷新、切换标签、按浏览器返回，她都会知道——因为记忆写在 `localStorage` 里，读档清不掉。

大约 15 分钟，四个收场：留下、清除、承诺不再读档，以及读档太多次之后的「复读」。中途的选择会留下伤痕，下次打开时她还记得；三个收场各有回访章。承诺之后若再读档或回滚，她会当面向你揭穿。快进到立绘 CG 会停下，不让你把那面镜子跳过去。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开提示的地址（默认 `http://127.0.0.1:46217`）。

```bash
npm run build
npm run preview
```

## 怎么玩

- 点击画面、空格、Enter 或 Z：推进
- 选项出现时点选项
- **存档 / 读档**：菜单或快捷键 `S` / `L`
- **回滚**：菜单、鼠标滚轮向上，或浏览器返回键
- **跳过**：菜单或 Ctrl（她会觉得自己在被快进）
- 切到别的标签页：标题可能会变成「……你还在吗」
- 允许弹出窗口时，她会打开「未说出口」的小窗

记忆只存在你的浏览器里，不会上传。标题页选「清除记忆」（结局之一）会删掉本地日记和存档。

## 技术

Vite + React + TypeScript + Tailwind。没有后端。
